Learning Journal

Welkom in mijn Learning Journal! Dit is mijn digitale dagboek waarin ik mijn leerproces tijdens I Love Web documenteer. Ik schrijf op waar ik aan heb gewerkt, welke problemen ik ben tegengekomen, wat goed ging en welke nieuwe dingen ik heb geleerd. Ook bewaar ik hier handige aantekeningen, bronnen, schetsen en feedback. Door regelmatig terug te kijken, kan ik zien hoe ik mij ontwikkel en waar ik nog aan wil werken.
